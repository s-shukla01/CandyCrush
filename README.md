A web-based clone of the popular **Candy Crush** puzzle game, built entirely with vanilla JavaScript, HTML, and CSS. The goal of the game is to swap adjacent candies to form lines of three or more of the same color, scoring points for every successful match.

## 🚀 Live Demo

Play the game directly in your browser:
**[https://candycrush-omega.vercel.app/](https://candycrush-omega.vercel.app/)**

## 🎮 Features

* **Classic Match-3 Gameplay:** Swap candies to create rows or columns of 3 identical items.
* **Score Tracking:** Real-time score updates as you crush candies.
* **Dynamic Grid:** The game board automatically refills with new candies after matches are cleared.
* **Visual Animations:** Smooth transitions for dragging and dropping candies.
* **Responsive UI:** Clean and colorful interface suitable for web browsers.

## 🛠️ Technologies Used

* **HTML5:** Structure of the game board and scoreboard.
* **CSS3:** Styling, grid layout, and animations.
* **JavaScript (ES6):** Game logic, event handling (drag/drop), match detection algorithm, and score calculation.

Bash
